# Code de conduite

CyberPath CI est un projet d'entraide entre étudiants et professionnels. On y attend :

- **Du respect** : pas d'insulte, de moquerie ni de harcèlement, quel que soit le niveau de la personne.
- **De la bienveillance envers les débutants** : toute question est légitime.
- **Une pratique éthique** : aucune aide pour attaquer un système sans autorisation, aucune donnée volée ou personnelle partagée.

Un comportement contraire peut entraîner le retrait d'un commentaire, d'une contribution ou l'exclusion du projet.

Pour signaler un problème : handcode0@gmail.com.
